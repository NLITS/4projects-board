# 4Projects Board

A free, open-source sticky-note whiteboard in a **single HTML5 file** — no install, no account, no server. Perfect for project kickoff sessions: capture what needs to be done as sticky notes, group them, and export straight into [4Projects](https://www.4projects.pro) as tasks & activities.

## Features

- **Sticky notes** — draggable, resizable, editable text, 6 colors, 3 sizes
- **Drawing** — freehand lines (pen) and rounded rectangles, with color & line width
- **Grouping** — lasso/shift-select notes → group them under a title; groups move together
- **Pan & zoom** — infinite-feeling canvas
- **Local storage** — auto-saves in the browser; also save/load board files (`.4pboard.json`)
- **4Projects export** — one click produces a JSON file that imports directly in 4Projects Free
- **5 languages** — NL / EN / DE / FR / ES

## Export mapping (to 4Projects)

| Board | 4Projects |
|---|---|
| Board name | Project + Fase |
| Group (title) | Task |
| Note in a group | Activity under that task |
| Loose note | Activity directly under the phase |

In 4Projects: **Bestand → Laden** and pick the exported `— 4projects.json` file.

## Usage

Open `4projects-board.html` in any modern browser — that's it. Works offline.

- 🗒 click = new note · ✏ draw · ▢ rounded frame
- Drag = select · Shift+click = multi-select · 👥 = group selection
- 👤 = ungroup · ⌫ = eraser · ✋ = pan
